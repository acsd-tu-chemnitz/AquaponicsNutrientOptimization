Info on running the code:

- The script CommercialFeed_Content.m calculates nutritional properties of a given feed. Feed need to be stated in a .csv file and have the same structure as the present PAFF* file.
	- Outputs are illustrated in figures and prompted in the command window

*Note: The authors do not take credit for the PAFF file as original research data. The file was downloaded from the website of the International Aquaculture Feed Formulation Database (IAFFD). 
Reference: IAFFD (2025). International Aquaculture Feed Formulation Database (IAFFD). https://www.iaffd.com/index.html. Accessed: 2025-06-04.
